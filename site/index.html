! The dashboard could not load its data

It tried to fetch data.json from alongside this page and the request did not come back.

Most likely cause. This page was opened straight off the filesystem by double-clicking the file, rather than being served. Browsers refuse fetch on a file:// page, so the data never arrives. Serve the folder over HTTP instead and open it through http://localhost.

From the dist directory that the build produced:

python3 -m http.server 8000

The other possibility is that the build never wrote data.json next to this page.

How to read a cell

  • ✓Passed the whole lifecycle
  • ✗Failed at a named step
  • ⊘Aborted, our runner stopped
  • ·No run that day

The bar under a cell is not decoration. Solid means that day counts in the pass rate. Dashed means a run happened but is left out of it, because an aborted run is our own outage and never a verdict on Akash. No bar means no run happened, which is also left out.

Source of record is schema/run.schema.json. Each cell is one run file, rendered as written, never re-graded by this page.
